プライバシーポリシー

スマホの Telegram から、Mac 上の Claude Code を動かす

最終更新：2026-09-23

Steward は何も収集しません

計測なし、解析 SDK なし、クラッシュレポートなし、いかなる形の送信もありません。 自ら発信する通信は Telegram Bot API のみ — それがこのアプリの仕事だからです。

bot token について

現バージョンではユーザー環境設定に平文で保存され、あなたの macOS アカウントから読み取れますが、 暗号化はされていません。この token はあなたの Mac へのリモート shell アクセスと同等です。 パスワードと同じ扱いをしてください。漏洩が疑われる場合は @BotFather で /revoke して再発行します。

Mac の外に出るもの

Steward は橋渡し役です。メッセージの内容を保存も解析も転売もしませんが、内容は 2 つの第三者を経由します：

  • Telegram — あなたと bot の間のすべてのメッセージは Telegram のサーバーを経由します。 Telegram のプライバシーポリシーが適用されます。
  • Anthropic — Claude に送った内容は、ローカルの claude プロセスから Anthropic へ 送られます。この経路は Claude Code 自身が管理しており、Steward はあなたのテキストを渡すだけです。 Anthropic のプライバシーポリシーが適用されます。

つまり Steward にはサーバーも、作者が覗けるバックエンドも存在しません。あなたのデータが開発者に届くことはありません。

Steward が Mac 上でできること

ここは一般的なプライバシーポリシーの項目ではありませんが、それより重要なので記載します。

Steward はあなたの権限で、サンドボックス外で動作します。キーボードの前にいるあなたと同じことができます — ファイルの読み書き、shell コマンドの実行、ネットワークアクセス。これは欠陥ではなく機能です。 Claude Code をリモートから動かすには、まさにこれらの権限が必要だからです。

この bot にメッセージを送れる人は、あなたの Mac で任意のコマンドを実行できます。 唯一の防御線は Telegram ユーザー ID の許可リストで、リストにないアカウントからのメッセージは黙って破棄されます。

  • 既定では、Claude が何か操作する（ファイル編集、コマンド実行）たびに、確認リクエストがスマホに届きます。
  • 許可リストにあるツールだけがこの確認を省略します。既定の許可リストは読み取り専用の操作のみです （Read、Grep、Glob、TodoWrite）。
  • 5 分間誰も応答しなかったリクエストは自動的に拒否され、通知が届きます。

該当しないもの

  • 個人を特定できる情報は収集しません
  • Cookie やトラッキング技術は一切使いません
  • 広告なし、第三者へのデータ提供なし
  • 13 歳未満の児童を対象としていません
  • アカウント登録は不要です

ポリシーの変更

将来のバージョンでデータの扱いが変わった場合（token をキーチェーンに移す、任意のログ出力を追加するなど）、 このページを更新し、リリースノートに明記します。

上記は現在の app 実装を説明したものです。Steward には解析、テレメトリ、クラッシュレポート、 サーバーコンポーネント、ログファイルはありません。

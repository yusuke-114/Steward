隐私政策

从手机上的 Telegram 操作你 Mac 上的 Claude Code

最后更新：2026-09-23

Steward 不收集任何数据

没有埋点、没有分析 SDK、没有崩溃上报，也没有任何形式的回传。它唯一主动发起的网络请求是 Telegram Bot API —— 因为那就是它的工作。

存在你本机上的东西

以下内容保存在你自己的 Mac 上，Steward 不会把它们发送到任何地方：

内容位置
Telegram bot token~/Library/Preferences/
允许的 Telegram user ID同上
项目目录列表、当前项目同上
工具白名单、权限超时设置同上
每个项目最近一次的会话 ID同上
运行日志仅内存，最多 1000 条，退出即消失，从不写入磁盘
关于 bot token 的一点提醒

当前版本把它以明文形式存在偏好设置里（文件权限 600，只有你本人的账号可读，但内容未加密）。 这个 token 等同于你 Mac 的远程 shell 访问权限，请像对待密码一样对待它。怀疑泄漏时，去 @BotFather 用 /revoke 作废并重新签发。

会离开你 Mac 的东西

Steward 是一座桥。它自己不存储、不分析、不转售任何消息内容，但消息确实会经过两个第三方：

  • Telegram —— 你和 bot 之间的所有消息都经由 Telegram 的服务器收发。适用 Telegram 隐私政策。
  • Anthropic —— 你发给 Claude 的内容，由本机的 claude 进程送往 Anthropic。 这条链路由 Claude Code 自己管理，Steward 只是把你的文字交给它。适用 Anthropic 隐私政策。

换句话说：Steward 没有服务器，也没有开发者能看到的后台。作者收不到你的任何数据。

Steward 在你 Mac 上能做什么

这一节不属于传统意义上的隐私政策，但比隐私政策更重要，所以写在这里。

Steward 以你的身份运行，且不在沙箱内。它能做的事和你坐在电脑前一样：读写文件、执行 shell 命令、访问网络。 这是它的功能，不是缺陷 —— 远程驱动 Claude Code 本身就需要这些权限。

能给这个 bot 发消息的人，就能在你的 Mac 上执行任意命令。 唯一的防线是 Telegram user ID 白名单：不在列表里的账号，消息会被静默丢弃。

  • 默认情况下，Claude 每次要动手（改文件、跑命令）都会把请求推到你手机上等你确认。
  • 只有白名单里的工具才跳过确认，而默认白名单只含只读操作 （Read、Grep、Glob、TodoWrite）。
  • 5 分钟内没人回答的权限请求会自动拒绝，并通知你。

不涉及的内容

  • 不收集个人身份信息
  • 不使用 Cookie 或任何跟踪技术
  • 不含广告，不与任何第三方共享数据
  • 不面向 13 岁以下儿童
  • 没有账号体系，无需注册

政策变更

如果将来版本改变了数据处理方式（例如把 token 迁移到钥匙串、或增加可选的日志落盘）， 本页会同步更新，并在发行说明中注明。

Steward 是开源软件，以上每一条都可以在源码中核实 —— 出站请求只存在于 TelegramClient.swift，日志实现见 LogStore.swift。
有疑问请在项目仓库提 issue。
